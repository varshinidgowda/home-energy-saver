# Home Energy Saver

A web app that helps students and families track home appliance electricity usage, see estimated monthly units and cost, and get tips to save energy.

Inspired by: Energy Consumption Tracker (Product Hunt)

## Tech Stack
- Next.js (JavaScript, App Router)
- React Context for global state
- Tailwind CSS
- Dummy data (no backend)
