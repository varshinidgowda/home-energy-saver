# Design System: Home Energy Saver

## 1. Colors
- Primary: #16A34A (green, saving energy)
- Secondary: #0EA5E9 (blue, charts and links)
- Background: #F8FAFC
- Text: #111827
- Accent: #F59E0B (amber, tips and highlights)
- Success: #22C55E
- Error: #EF4444

## 2. Typography
- Font: Geist Sans (default in Next.js)
- H1: 32px / Bold
- H2: 24px / Semi Bold
- Body: 16px / Regular
- Button text: 16px / Medium
- Small text: 14px / Regular

## 3. UI Components
- Navbar
- Footer
- StatCard
- Button
- Input
- Card
- Badge
- Chart
- EmptyState

## 4. UI Decisions
- Clean, light layout with plenty of white space
- Green used for savings, amber for warnings and tips
- Responsive design for mobile and desktop
